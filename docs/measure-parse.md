# Corpus measurement: ingredient lines

Source: `data/source/recipes-recepten2.json` — generated by `npm run measure-parse` (tools/measure-parse.ts).
Regex-only classification, no dictionary lookup. This estimates the *shape* of the corpus,
not parse success (that is what the phase-2 golden fixture measures). Re-run to reproduce.

Kinds: `qty-known-unit` = quantity + known unit ("400 g …"); `qty-count-or-name` = quantity
followed by a count word or the name itself ("2 eieren", "1 rode ui"); `no-qty` = no leading
quantity ("zout en peper"); `header` = trailing colon ("Dressing:").
